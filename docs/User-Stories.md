# Personal Budget App - User Stories

## Table 1 User Stories

## USID01 - User Login	   								
#### As a user, I want to sign in securely, so that i can manage my transactions securely

## USID02 - Add Transaction 	 
#### As a user, I want to record my personal transactions, so that I can track my transactions

## USID03 - Update Transaction 	 
#### As a user, I want to modify my transactions, so that I can correct any incorrect 	        records (transactions)

## USID04 - Delete Transaction 
#### As a user, I want to delete my transactions, so that I can remove any unnecessary 	          records (transactions)

## USID05 - View Transaction Details 
#### As a user, I want to view my transactions, so that I can view my own transcations	   

## USID06 - View Transaction by mode
#### As a user, I want to check the mode of transactions using visuals, so that I am able to obtain an insight into my transactions and their modes in visual form easily
