# Personal Budget App - Requirements

## Functional requirements

**User can register/login**
**User can add transaction**
**User can edit/delete transactions**
**User can view transaction mode by category**

## Non-functional requirements

**User inputs should be validated**
**The application should be compatible with different device views**
**The API should respond within an acceptable time**
**User data should be protected**
**Database operations should maintain data integrity**
