# Personal Budget App - Acceptance Criteria

## Table 1 User Stories

## USID01 - User Login	   								
**User authentication is required before accessing any transactions**

## USID02 - Add Transaction 	 
**User can add and save transaction details**

## USID03 - Update Transaction 	 
**User can modify own existing transaction details**

## USID04 - Delete Transaction 
**User can remove unnecessary transaction details**

## USID05 - View Transaction Details 
**User can see their own transaction details**	   

## USID06 - View Transaction by mode
**User can see their own transaction details based on its mode via a visual chart**
